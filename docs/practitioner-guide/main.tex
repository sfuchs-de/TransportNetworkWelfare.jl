{\large\bfseries\color{guideblue}Purpose and scope\par}
\vspace{0.65em}
This guide evaluates which existing transport link would generate the largest
model-implied economic benefit from a small improvement. Starting from
model-consistent directed flows, location shares, and calibrated elasticities,
the package reports the Traditional approach, full realized- and primitive-cost
welfare effects, exact model comparisons, and numerical diagnostics.
At an efficient interior baseline, the Traditional approach is exact even though
routes, modes, prices, and locations adjust. Congestion and spatial
externalities create the correction measured by the extended statistic.

\vspace{0.7em}
A self-contained 25-location economic-geography grid with a central transit
spine provides the worked application. The output is a marginal gross-benefit
measure rather than a complete appraisal: construction and financing costs,
safety, pollution, distributional effects, and transition dynamics require
separate evidence. The grid and this guide can be rebuilt without external
application data, private credentials, an Overleaf checkout, or Python
plotting packages. The U.S. freight and Seattle modules require external data.
The Sioux Falls and Westeros builders likewise download hash-pinned source
files rather than redistributing them.

\part{Quick start}
\label{part:quickstart}
\addtocontents{toc}{\protect\setcounter{tocdepth}{1}}
A new application fails if its policy unit, flow unit, and spatial model are
chosen independently. Part I fixes those choices together, documents the
source data, constructs model-ready inputs, and produces validated welfare
results, maps, and an archived run manifest.
