\begin{abstract}
This guide explains how to measure the local welfare effect of a transport-cost
change in a spatial equilibrium model and how to carry out that calculation
with \texttt{TransportNetworkWelfare.jl}. It is written for applied researchers
seeking to understand the economic object before running the code.

The economic-geography model is the guide's main specification. It corresponds
to Allen, Fuchs, and Wong, ``From Social Savings to Spatial Equilibrium:
Evaluating Transportation Improvements in Quantitative Spatial Models.''
The urban commuting model and endpoint-terminal congestion are presented as
extensions. The positive-power modal index remains available only to reproduce
an earlier computational vintage.

The distributable examples include all required inputs. A reader can install
the Julia package, run the examples, and rebuild this PDF without private data.
The U.S. freight and Seattle applications require external inputs. Their
adapters, hashes, assumptions, and aggregate results are documented, but the
restricted files are not included.
\end{abstract}

\paragraph{Reading guide.}
Applied users can begin with Sections \ref{ch:question}, \ref{ch:data},
\ref{ch:code}, and \ref{ch:worked}. The derivation runs from Sections
\ref{ch:equilibrium} through \ref{ch:ift}. Package contributors should also
consult Section \ref{ch:diagnostics} and Appendices
\ref{app:algorithm}--\ref{app:verification}. The empirical adapters are
described in Sections \ref{ch:rsue} and \ref{ch:extensions}.
