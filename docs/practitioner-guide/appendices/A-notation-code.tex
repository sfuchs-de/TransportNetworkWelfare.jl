\label{app:crosswalk}

Sections \ref{ch:equilibrium} and \ref{ch:welfare} present the two spatial
models and their common transport calculation in economic notation. This
appendix records the corresponding code quantities and fixes the
orientation and sign conventions used by the algorithms in Appendix
\ref{app:algorithm}.

\subsection{Orientation conventions}

An edge tuple \((i,j)\) means origin \(i\), destination \(j\). In the
row-oriented continuation matrix \(\mu\), the element \(\mu_{ij}\) is the share
leaving \(i\) on edge \(i\to j\). The inward share is stored using the same edge orientation,
with destination exposure in the denominator. Code that differentiates the
second market-access recursion uses the transpose where required.

The policy selector indexes positive-flow edge-mode pairs rather than all
possible matrix cells. The directed result retains both integer indices and
source IDs.
Physical aggregation relies on endpoint IDs and the declared
\code{physical\_link\_id}, not adjacency-matrix symmetry alone.

\subsection{Signs}

Costs enter as log increases, while reported benefits correspond to cost
reductions:
\[
 E_p=-\frac{d\log W}{d\log\bar\kappa_p}.
\]
The Hulten traffic share is positive. The primitive and realized elasticities
are stored as positive benefits under this convention. Decomposition wedges
and decomposition components remain signed and can be negative.

The coefficient \(\rho\) can be negative. Do not replace signed products by
absolute values. A negative \(\rho\) and negative access multiplier sum can
produce a positive benefit.

\subsection{Legacy aliases}

The mathematical audit and early code use ``node-visit stock'' or
``occupation stock'' for the recursive exposure quantity. These are technical
descriptions of the resolvent. The paper and guide use ``trade exposure'' for
\(\mathcal T_i^G\) and ``commuting exposure'' for \(\mathcal T_i^U\). The
code function name is preserved for compatibility.

The positive-power modal type \code{ComponentCES} is \textbf{legacy-only}.
Its congestion helpers are not part of the active \code{ChoiceLogsum}
implementation. The distinction changes the economics of modal substitution;
it is not a cosmetic sign convention.
